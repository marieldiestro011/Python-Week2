# Week 2 - Python Inventory Projects

This repository contains my Week 2 Python practice projects. These programs demonstrate basic inventory management and inventory value calculations.

## Projects

### 1. Simple Inventory
File: `SimpleInventory1.py`

A beginner Python program for practicing how to store and display product information.

### 2. Inventory Value Calculator
File: `InventoryValue2.py`

A Python program that allows users to enter product names, prices, and quantities.

**Features:**
- Add multiple products
- Store product information using dictionaries and lists
- Display product names, prices, and quantities
- Calculate product inventory values

## Technologies Used
- Python
- Visual Studio Code

## Concepts Practiced
- Lists
- Dictionaries
- While loops
- For loops
- User input
- Basic calculations

## How to Run

Open the terminal in VS Code and type:

```bash
python SimpleInventory1.py
```

Or:
